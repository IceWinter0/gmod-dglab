# gmod-dglab

Garry’s Mod 与郊狼 DG-Lab 3.0 联动项目。通过注入式 Rust DLL 采集本机游戏状态，由独立桌面控制面板配置联动规则、强度和波形。

> 项目目前处于架构设计与二进制适配调查阶段，尚无可用正式版本。下列内容是开发目标，不代表已实现或已通过实机验证。

## 首版目标

- 仅支持 Windows 64 位与 GMod x86-64 / Chromium 分支。
- 仅支持郊狼 3.0 硬件，计划兼容 DG-Lab APP 3.x 与 4.x。
- 在本机注入 Rust DLL，无需安装服务器插件或修改服务器。
- 根据本地玩家血量与生命状态变化，触发受伤、死亡和重生联动。
- 提供双通道强度、波形预设、规则配置、事件日志和停止操作。
- 仓库介绍、使用文档、面板文案和发布说明使用简体中文。

## 架构

```text
GMod 中的 Rust DLL
    │ 本机事件与心跳
    ▼
独立桌面控制器
    ├─ Rust 控制核心：规则、限幅、调度与设备连接
    └─ 桌面面板：配置、状态与日志
    │
    ▼
DG-Lab APP → 郊狼 3.0
```

客户端只能使用实际收到的信息。血量下降属于近似受伤信号，无法保证还原服务器上的每次伤害、攻击者或伤害类型。
